# eureka-server

Реестр сервисов Netflix Eureka. Порт 8761, dashboard - http://localhost:8761.

Сервер сам не регистрируется и не забирает реестр. Режим самосохранения отключён, чтобы
в учебном проекте остановленные экземпляры пропадали из реестра быстрее (eviction раз в 10 с).

Клиенты находят сервер по `EUREKA_URL` (по умолчанию `http://localhost:8761/eureka`).
